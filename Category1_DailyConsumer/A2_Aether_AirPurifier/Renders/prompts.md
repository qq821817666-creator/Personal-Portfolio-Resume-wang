## APPENDIX: Generation Notes / 生图备注

### Consistency Requirements / 一致性要求

| Parameter | Value |
|---|---|
| **Product form** | Cylindrical tower, h≈65cm, d≈28cm, soft-radius top and bottom |
| **Camera angle (04-07)** | Front 3/4, eye-level (~100cm height), product centered |
| **Studio lighting (04-07)** | 5500K daylight-balanced, softbox left key + fill right, no hard shadows |
| **Interior lighting (04-06)** | Natural window light, morning-to-noon quality, warm ambient |
| **Material references** | See Phase 3 spec tables for exact Pantone, CIELAB, texture codes |

### Per-Shot Checklist / 单张检查清单

Before considering a render "final," verify:
- [ ] Wood-fiber body: visible particle texture, matte (3-5 GU), warm beige/gray/green per variant
- [ ] Felt grille: soft textile surface, heathered (fiber-level color mixing), not flat-dyed
- [ ] Base ring: natural material grain (bamboo/walnut/cork), open-pore, not glossy
- [ ] Ceramic ring: matte glaze, dense/smooth, no plastic-like reflections
- [ ] LED diffuser: reads as solid surface when off, subtle etched dot pattern visible in macro
- [ ] Product scale: reads as furniture-object (~65cm tall), not desktop gadget
- [ ] Color accuracy: close to Pantone references from Phase 3 spec tables

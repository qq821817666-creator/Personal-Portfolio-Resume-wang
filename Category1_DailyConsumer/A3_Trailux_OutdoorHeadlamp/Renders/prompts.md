## Generation Notes / 生图备注

| Parameter | Value |
|---|---|
| **Product form** | Compact headlamp, ~65mm wide × 40mm tall × 35mm deep, central lens + top button |
| **Camera angle (04-07)** | Front 3/4, ~30° above product, product centered |
| **Studio lighting (04-07)** | 5500K key + rim light, dark gradient background |
| **Material references** | See Phase 3 spec tables for exact Pantone, CIELAB, texture codes |
| **Color attitude** | Accent buttons must read as "lichen/safety/nature" not "toy/plastic/kids" |

### Per-Shot Checklist
- [ ] Stone texture: MT-11030 crystalline roughness, matte 2-3 GU, dark gray
- [ ] Aluminum ring: real metal luster, laser-etched grip lines visible, anodized tone
- [ ] Silicone button: matte dome, high-vis color, tactile profile
- [ ] Headband: woven elastic texture, reflective thread catch light, color per variant
- [ ] Product scale: compact (~65mm wide), reads as premium outdoor gear, not toy
- [ ] Color accuracy: close to Pantone references from Phase 3 spec tables

# B1: Flux — 城市电动滑板车
# Urban E-Scooter | 工业设计

> **流程:** 调研 → 竞品 → 画像 → 草图方向 → CMF → 渲染
> **参考视觉:** 微喷砂铝合金 × 天然木材暖触感 × 城市机能美学 × 材料随时间生长的痕迹

## 1. RESEARCH / 调研

### 1.1 市场背景

全球电动滑板车市场 2025 年超 $40B，共享出行退潮后个人购买成为增长引擎。核心矛盾：**滑板车是功能工具，但它占据你的生活空间**——停在公寓玄关、靠在办公桌旁、折叠后塞进咖啡店角落。一个设计差的车，停在客厅就是视觉噪音。

**核心洞察:** 市面滑板车全都做"电动工具"——黑色塑料、廉价橡胶、螺丝外露。Flux 要做的是**停在公寓里像一件设计师家具，骑在路上才展现城市机能**。材料必须允许自然老化——使用痕迹读作"故事"而非"损坏"。

### 1.2 使用场景

| 场景 | 环境条件 | 设计影响 |
|---|---|---|
| 日常通勤 | 城市街道、人行道过渡、轻微颠簸 | 车架抗刮擦、折叠机构顺畅、把套耐汗 |
| 雨天湿滑 | 积水、泥沙、潮湿 | IPX5 防水、挡泥板有效覆盖、甲板防滑 |
| 夜间骑行 | 低光、车灯照明 | 反光细节、铜/金属件在车灯下可见 |
| 室内停放 | 玄关、客厅、办公室角落 | 必须读作"家具/配饰"而非"工具/机械" |
| 周末休闲 | 公园小径、河滨道、露天咖啡 | 阳光下色彩呈现、材质随光线变化 |
| 地铁/公交接驳 | 快速折叠、手提搬运、靠墙停放 | 15kg 以内轻量化、折叠锁定牢靠 |

### 1.3 关键需求提取

1. **公寓可见性** — 停在客厅不是一件丑东西。设计必须从住宅室内角度审视。
2. **全天候耐用** — 雨水、泥沙、紫外线。IPX5、UV 稳定、易清洁表面。
3. **轻量化** — ≤15kg，单手可提上地铁台阶。铝框核心。
4. **触感优先** — 每天手接触的部位（把套、甲板）必须高级——木头温感、软胶回弹。
5. **反盗窃设计** — 关键部件（车铃、轮毂）非标紧固件，减少快拆风险。
6. **材料老化故事** — 黄铜铃自然氧化、木头甲板随脚步变深——使用 1000km 后比第一天更有个性。

| 竞品 | 型号 | CMF | 优势 | 劣势 → 机会 |

| **Xiaomi** | Electric Scooter 4 Ultra | 黑/灰塑料主体、红色线管点缀、橡胶甲板 | 价格亲民、渠道广泛、折叠紧凑 | 塑料感强。黑色统一但廉价。停在家里像工具。 |

**差异化定位:** 所有竞品把滑板车当成"出行装备"做——塑料、黑色、功能即正义。**没有一款把滑板车当成"城市配饰+家具物件"做。** Flux 的机会：第一个以**材质叙事 + 室内美学**驱动的电动滑板车。木头、黄铜、微喷砂铝——这些材料在室内设计语境里成立，在室外则自然老化出个性。

## 3. USER PERSONA / 用户画像

### 城市创意人 — 林抒

- 29 岁，独立设计师 / 自由职业者，上海
- 住在 50平米公寓，玄关 = 第一印象。任何丑东西都不能进
- 每天通勤 6km：家 → 共享工作室 → 咖啡店 → 家。滑板车是"随身城市锚点"
- 他选东西的标准："我每天看到它、摸到它、用到它。它要配得上我的生活。"

**他对滑板车的期待:**
1. 停在玄关不丑陋——客人来的时候不需要踢到角落里
2. 淋雨后擦干就行——第二天不会吱嘎响或生锈
3. 握把和甲板触感温热——不是冰冷的工业塑料
4. 用过半年后比全新的更有味道——木头变深、黄铜长斑、铝有细痕但那是他在城市留下的地图
5. 颜色不要太"运动"也不要太"商务"——像一家好的独立咖啡店选的那种色调

## 4. SKETCH DIRECTION / 草图方向

### 4.1 形态关键词

| 方向 | 关键词 |
|---|---|
| **整体姿态** | 低重心、水平线性、纤薄比例——"浮在路面上的甲板" |
| **体量分布** | 甲板为主视觉锚点 + 立杆细长脊线 + 紧凑折叠铰链 |
| **结构语言** | 干净折面/管身曲线/可视榫接——三个方向三种结构表达 |
| **人车接触点** | 天然木材甲板边、软胶双料把套、黄铜机械铃——材质物理连接而非包裹 |
| **折叠表达** | 铰链机制做主角——不对折时是精密机械细节，对折后是紧凑方块 |

### 4.2 三个草图探索方向

**方向 A: "Origami / 折纸" — 折叠平面**
视觉隐喻: 一张纸折出来的形体。车架由连续几何折面构成——每个折角都是结构加强筋。管身截面是多边形而非圆形，干净利落的平面转折贯穿从头到尾。立杆与甲板的连接是一道折痕而非一个螺栓。参考：日本折纸构造、Bird 电动滑板车的一体折面、SANAA 建筑的薄板逻辑。最"纯粹几何"的方向。

**方向 B: "Drift / 漂移" — 动态雕塑**
视觉隐喻: 被城市风速线雕刻出的有机形体。铝框管身有渐变的截面变化——从圆形过渡到椭圆再到扁平，模拟空气绕过车体的流线。前叉和挡泥板像被风吹鼓的帆布。车把微微后掠——静止时也有速度感。参考：Zaha Hadid 流体建筑、Bianchi Oltre 公路车的空气动力学管型、风的侵蚀地貌。最"骑行感"的方向。

**方向 C: "Joinery / 榫卯" — 材质节点**
视觉隐喻: 不是"造"一台车，而是"拼"一件家具。不同材质之间通过明确的结构节点物理连接——铝框插入木甲板的 CNC 铣槽、黄铜铃用燕尾槽卡入车把、把套热压套入管端露出一圈干净的材质边界。每个连接点都是故意展示的视觉焦点，像日式木工的仕口。参考：Carl Hansen 椅子榫接、Brompton 折叠铰链、日本指物木工。最"家具感"的方向。

### 4.3 推荐方向

**C (Joinery / 榫卯) 为主 + A (Origami / 折纸) 的简洁几何**

C 的材质节点语言直接回应核心用户诉求——"停在公寓里像设计师家具"。铝框+木甲板+黄铜铃通过可视的物理节点连接，每一处接合都是值得细看的细节。A 的折纸几何提供干净利落的结构线——多边形管身截面的折角形成天然加强筋，减少材料用量的同时增加视觉张力。

B 的有机曲线不选的原因：渐变截面管身对折叠铰链的机械精度要求极高，且流体形态在折叠状态下难以保持视觉逻辑——展开时是一条风速线，折起来是一团乱线。

## 5. CMF / 色彩·材质·表面处理

### 5.1 核心配色

| 角色 | 颜色 | Hex | 光泽 | 用途 |
|---|---|---|---|---|
| 主车架 | 暖混凝土灰 | #C8BFB4 | 8-15 GU | 最大面积——锻造铝框 + 微喷砂 |
| 功能点缀 | 安全橙 | #E06030 | 10-20 GU | 阳极氧化点缀——折叠扣、线管束环、铃铛底座 |
| 甲板 | 枫木原色 | #C4A882 | 3-8 GU | 加拿大枫木 + 透明密封——天然木纹可见 |
| 把套 | 深炭灰 + 橙点 | #383430 | 2-4 GU | TPE 双料注塑——主黑底 + 橙色微颗粒 |
| 轮毂 | 枪灰 | #4A4844 | 5-10 GU | 拉丝铝 + 透明阳极——低调金属光泽 |
| 挡泥板 | 暖灰（与车架匹配） | #C0B7AD | 3-5 GU | 回收 PP——模内纹理，哑光 |

### 5.2 三个变体

**V1: Concrete Dawn / 混凝土黎明**
暖混凝土灰车架 + 安全橙阳极点缀 + 枫木甲板 + 深炭灰/橙点把套 + 枪灰轮毂 + 原黄铜铃（不涂装、任其氧化）。

城市清晨的第一道光——暖灰色调像刚醒的混凝土建筑，安全橙是朝阳反射在玻璃幕墙上，木头是你手里那杯热咖啡。

**V2: Midnight Flow / 午夜流动**
深海蓝车架 + 电光青阳极点缀 + 枫木甲板（天然边+黑砂 grip）+ 黑/青点把套 + 暗铬 PVD 轮毂 + 拉丝不锈钢铃。

城市深夜——深蓝车架在路灯下几乎呈现黑色，电光青像 LED 屏幕在暗处的辉光。最"都市夜景"的变体，夜间安全可见的同时保持沉静。

**V3: Botanical Commute / 植物通勤**
鼠尾草绿车架 + 暖沙回收铝点缀 + 竹复合甲板（天然橡胶 grip）+ 软木/TPE 混合把套 + 暖香槟轮毂 + 回收黄铜铃。

把城市绿植带到路面——鼠尾草绿是地铁站旁的社区花园，暖沙是旧砖墙，竹子是周末公园。最"有机"的变体，阳光下的层次最丰富。

### 5.3 关键细节

- 木甲板边缘 — 透明密封保留天然木纹，不留漆皮剥落可能。可更换 grip tape（减少浪费）。
- 黄铜铃 — 不涂装。出厂抛光，3 个月自然氧化出独一无二的纹路，6 个月后呈现温暖的暗金色。
- 微喷砂铝面 — *120 玻璃珠喷砂，划痕被纹理本身"吸收"——不像亮面铝那样一道划痕就是一条白线。
- 所有外装紧固件 — M5/M6 内六角，统一枪灰色锌镀层。一把工具全车通修。
- 折叠铰链 — 车身上唯一的高光区域（15-25 GU 半光黑），与哑光车架形成"机械关节"对比。

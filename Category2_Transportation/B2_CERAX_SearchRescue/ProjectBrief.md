## 1. RESEARCH / 调研

### 1.1 市场背景

全球搜救机器人市场预计 2030 年达 $15B。驱动因素：自然灾害频率上升（气候变化）、城市化（更多坍塌脆弱建筑）、机器人在近期灾难中的实战验证（福岛、土耳其-叙利亚地震、迈阿密公寓坍塌）。

**核心洞察:** 机器人进入人类不能进、不该进的空间。它会被刮伤、撞凹、满身碎石灰尘。CMF 必须让这些读作"服役荣誉"而非"损坏"。

### 1.2 使用场景

| 场景 | 环境条件 | 设计影响 |
|---|---|---|
| 地震废墟 | 不稳定结构、混凝土碎片、钢筋暴露、灰尘 | 层叠装甲吸收冲击、暗色隐藏灰尘 |
| 洪水区 | 积水、淤泥、漂浮物 | IP67+ 防水、排水面板 |
| 火灾周边 | 高温、烟雾、化学残留 | 耐高温材料、抗化学涂层 |
| 山崩/雪崩 | 低温、冰雪、岩石 | -30°C 运行、明亮金属件提高雪地可见度 |
| 夜间作业 | 低光、手电筒照明 | 铜色接口在灯光下可见、哑光减少眩光 |

### 1.3 关键需求提取

1. **抗冲击** — 落石、坍塌碎片。IK08 以上。
2. **战地可修** — 面板 5 分钟内用一把工具更换。标准化紧固件。
3. **低光可操作** — 关键接口在黑暗中可见。
4. **极端温度** — -30°C 到 +60°C。
5. **文化中立** — 同一台机器可能部署到土耳其、日本、美国。必须读作"救援装备"而非"军用硬件"。

## 2. COMPETITIVE AUDIT / 竞品分析

| 竞品 | SAR 配置 | CMF | 优势 | 劣势 → 机会 |
|---|---|---|---|---|
| **Boston Dynamics Spot** | 摄像头桅杆 + 机械臂 | 黄/黑工业塑料、暴露传感器 | 强机动性、关节处可视工程 | 塑料机身读作"实验室改造"。黄色=工地设备。无装甲保护。 |
| **ANYbotics ANYmal** | 检测传感器、自主导航 | 深灰/黑金属+塑料、紧凑四足 | 坚固。暗色藏污。紧凑=易部署。 | 为工厂巡检设计，非SAR。表面细节少。读作"传感器平台"。 |
| **履带式 (Telemax/PackBot)** | 履带平台 + 机械臂 | 军绿/黑、暴露履带 | 实战验证。军用级耐用。 | 军绿色限制民用SAR部署。履带在碎石地形慢于腿式。老旧平台设计。 |
| **大疆 / 无人机方案** | 空中搜索、热成像 | 白/灰消费级塑料 | 空中视角无可替代。低成本。 | 纯视觉。无物理交互能力。无法进入坍塌结构内部。 |

**差异化定位:** 当前没有一款 SAR 机器人占据"专业救援装备"的 CMF 位置。Spot 是实验室→现场改造，ANYmal 是工厂→现场改造，PackBot 是军用→民用改造。**机会：一台从第一天就为废墟、雨水和救援设计的机器人。**

## 3. USER PERSONA / 用户画像

### 搜救队长 — 陈队长

- 42岁，消防/搜救系统 17 年
- 经历过 3 次大地震、无数次建筑坍塌
- 他评估装备的方式："这个在我最需要的时候会不会坏？""我的队员能不能在凌晨 3 点用冻僵的手修好它？"
- 机器人对他来说不是 gadget — 是替他进入危险空间的"队友"

**他对机器人的期待:**
1. 进入人类进不去的空间
2. 被碎石砸中后继续工作
3. 5 分钟内完成战地面板更换
4. 黑暗环境里一眼看出哪个接口需要检查
5. 50 次任务后比第 1 次更值得信任 — 因为那些划痕证明了它在哪工作过

## 4. SKETCH DIRECTION / 草图方向

### 4.1 形态关键词

| 方向 | 关键词 |
|---|---|
| **整体姿态** | 低重心、宽站姿、紧凑比例 — "蹲伏的守护者" |
| **体量分布** | 厚重底盘 + 精简上部 — 稳定感优先 |
| **装甲语言** | 层叠面板、非对称分割、功能分缝 — 每道缝都是吸能线 |
| **关节表达** | 暴露旋转机构、多层密封环、枪灰结构框 — "你可以看到它是怎么动的" |
| **传感器头部** | 暗色透明视窗、多目阵列、保护笼架 — 像防毒面具或飞行员头盔 |

### 4.2 三个草图探索方向

**方向 A: "甲虫" — 弧面装甲 + 紧凑包裹**
灵感: 昆虫外骨骼。圆润的功能曲线包裹内部机械。面板块数少、面积大。适合快速清洗——泥水一冲即净。

**方向 B: "棱镜" — 硬朗折面 + 几何切割**
灵感: 隐形战机。锐利折面、角度分明的面板分割。每一刀都有功能——导流雨水、减少雷达反射、增强结构刚性。最"军用"的方向。

**方向 C: "工装" — 框架外露 + 模块插件**
灵感: 建筑机械。核心骨架暴露，功能模块（电池、传感器、机械臂）像工具包一样挂在骨架上。最大程度的"战地可修"——任何模块 30 秒更换。最"民用救援"的方向。

### 4.3 推荐方向

**B (棱镜) 为主 + C (工装) 的模块化理念**

B 的硬朗折面语言最符合"专业救援装备"的定位——与消费级机器人拉开距离。C 的模块化设计确保战地可修。A 的弧面元素可以用在少数大面积面板上作为视觉呼吸点。

## 5. CMF / 色彩·材质·表面处理

### 5.1 核心配色

| 角色 | 颜色 | Hex | 光泽 | 用途 |
|---|---|---|---|---|
| 主装甲 | 暗石墨 | #3A3835 | 15-25 GU | 最大面板区域 |
| 副装甲 | 哑黑金属 | #2A2825 | 2-5 GU | 对比面板、下层装甲 |
| 结构框 | 枪灰 | #4A4844 | 5-10 GU | 关节处暴露 |
| 液压线 | 金属银 | #8A8680 | 20-30 GU | 管线 |
| **服务标记** | **铜色** | #B87850 | 15-25 GU | 液压接口、电池仓 — 唯一的暖色 |
| 线缆护套 | 深炭灰 | #383430 | 2-4 GU | 橡胶 |

### 5.2 三个变体

- **V1 工业标准:** 暗石墨 + 铜色接口 — 均衡战场作业
- **V2 原生金属:** 枪灰主装甲 + 黄铜接口 — 极地/山岳搜救，雪地中更可见
- **V3 全黑:** 全黑金属 + 暗黄铜 — 夜间/隐蔽作业，最低反光

### 5.3 关键细节

- 面板间隙 1.5-2mm → 受冲击时微移，不传递裂纹
- 全部外装紧固件标准化 M5/M6 Torx → 一把工具全场通修
- 铜色仅用于液压接口和电池仓 → 低光下的快速定位标记
- 边缘自然磨损露原金属 → 50 次任务后的服役勋章
